# Jarvis AI Assistant 🚀

A personal AI-powered assistant that:
- Analyzes learning roadmaps
- Generates structured tasks
- Tracks progress
- Suggests next actions
- Provides voice-based interaction

## Tech Stack
- Java (Spring Boot)
- OpenAI API
- Notion (Dashboard)
- TickTick (Reminders)

## Features (MVP)
- Roadmap → Task conversion
- Smart task suggestion
- Scheduler-based reminders
- AI-powered planning

## Future Enhancements
- Voice automation
- Full dashboard UI
- Advanced scheduling engine
